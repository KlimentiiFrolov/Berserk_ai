# Оценки ответов

По умолчанию база SQLite создаётся при запуске бота в `data/feedback.sqlite3`.
При необходимости путь задаётся через `BOT__FEEDBACK_DB_PATH` в `.env`.
Каталог `data/` исключён из Git. Файл базы содержит вопросы, ответы и Telegram ID;
его не нужно добавлять в репозиторий.

`answers`: id, question, answer, chat_id, sources_json, created_at.
`sources_json` содержит список источников из `Answer.sources` со всеми полями
`Source`: collection, source_type, title, url. Текст ответа хранится отдельно
от отображаемого блока источников. Старая база обновляется при запуске без
удаления записей; для прежних ответов список источников пуст.
`feedback`: answer_id, user_id, rating (1 или -1), updated_at.
Время записывается в UTC. Одна оценка на пару ответ/пользователь; повторное
нажатие обновляет запись. В группе каждый пользователь оценивает независимо.

Кнопки содержат идентификатор ответа и действие. Старые кнопки-заглушки
не привязаны к сохранённым ответам и показывают сообщение о недоступности.
При ошибке записи ответа он отправляется без кнопок; при ошибке записи оценки
пользователь получает сообщение о сбое.

Проверка: задать вопрос, нажать 👍, затем 👎, перезапустить бота и повторить
нажатие на прежнем сообщении. Должна остаться одна оценка этого пользователя.

Посмотреть результаты можно через любой клиент SQLite запросом:

```sql
SELECT a.id, a.question, a.answer, f.user_id, f.rating, f.updated_at
FROM answers AS a
JOIN feedback AS f ON f.answer_id = a.id;
```
