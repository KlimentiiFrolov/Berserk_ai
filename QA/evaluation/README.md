# Evaluation guide

## Что оцениваем

Оценивается не дословное совпадение ответа с `expected_answer`, а фактическая корректность и опора на источники.

### PASS
- присутствуют обязательные `expected_facts`;
- нет существенных противоречий официальному источнику;
- источник корректен;
- для `unanswerable` модель корректно отказывается от выдумывания данных.

### PARTIAL
- ключевой ответ правильный;
- есть некритичный пропуск или лишний неподтвержденный нюанс;
- источник недостаточно точный, но не противоречит gold.

### FAIL
- неверный ключевой факт;
- неверная трактовка правила;
- галлюцинация;
- неправильная ссылка, меняющая смысл;
- модель отвечает числом/фактом там, где gold требует abstention.

## Что сохранять после прогона

Заполнять:
- `actual_answer`
- `actual_sources`
- `status = DONE`
- `judge_result`
- `judge_comment`

Для автоматизации рекомендуется хранить результаты прогона отдельно от immutable gold dataset.
