# Smoke tests

Минимальная проверка жизнеспособности MVP после сборки/деплоя.

## P0
Если падает хотя бы один P0 smoke-test, сборку не считаем пригодной для дальнейшей функциональной проверки.

## P1
Проверки важны для пользовательского сценария и regression seed, но могут временно блокироваться отсутствующей функциональностью текущего спринта.

`smoke_tests.json` специально отделён от gold dataset: smoke проверяет, что система вообще жива, а gold dataset — качество ответа.
